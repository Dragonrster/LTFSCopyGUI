# CM 解析器（CmParser）

独立的 CM 查看工具：打开并解析 LTFSCopyGUI 保存的 `.cm` 文件，按“应用信息 / 使用情况 / 磁带信息 / 磁带数据”分区显示；若文件中包含 CM 原始数据，还会从 `CM RAW DATA` 十六进制区恢复 8160/4096 字节 CM buffer，**完整解析**全部 CM 字段。

- **不访问磁带设备**，不需要带库或驱动器。
- 文件来源：`带库操作 → 批量读取CM` 保存的报告，或备份索引时自动生成的 `.cm`（`schema\<条码>\CM_<时间>.cm`）。
- 支持直接打开原始 CM 二进制 dump（磁带 READ BUFFER 0x3C/0x10 导出的 4096 或 8160 字节数据）。
- 支持批量管理：选择文件夹后递归扫描其中的 `.cm` / `.txt` / `.bin`，表格总览并支持关键字筛选。
- 缺失字段显示「不可用」。

## 使用

1. 运行 `CmParser.exe`。
2. 点击「打开 CM 文件」，或把文件拖放到窗口；也可以命令行传入路径：

   ```text
   CmParser.exe "C:\...\schema\MX7219L4\CM_20261024_003629.cm"
   ```

3. 「完整解析」按钮：显示从 CM 原始数据解析出的全部字段（分类 / 字段 / 值，可复制）。文件不含原始数据（无 `CM RAW DATA`）时该按钮不可用。
4. 「原始报告」按钮：查看报告原文。

## 批量管理

点击「批量管理」打开列表窗口：

1. 「选择文件夹」后递归扫描该文件夹及子文件夹中的 `.cm` / `.txt` / `.bin` 文件，逐个解析；选择文件夹的弹窗支持直接输入或粘贴路径（也可点「浏览」选择）。
2. 表格列出每盘的条码、格式、序列号、厂商、生产日期、加载次数、累计写入/读取、完整卷等效量、分区数、估算容量损失、文件大小、解析状态和文件路径；点击列头排序（数值列按数值大小、文本列按文本排序，再点一次切换降序）。
3. 顶部「筛选」框按条码 / 格式 / 序列号 / 文件路径过滤；解析失败的行以红色显示并列出失败原因。
4. 扫描过程中可「取消」；完成后状态栏显示文件总数与成功/失败数量。

## 构建

用 Visual Studio 打开 `CmParser.vbproj` 编译，或用 MSBuild：

```text
msbuild Tools\CmParser\CmParser.vbproj /t:Rebuild /p:Configuration=Release /p:Platform=AnyCPU
```

需要 .NET Framework 4.8 目标包。产物：`Tools\CmParser\bin\Release\CmParser.exe`。

解析逻辑位于 `CmParserCore.vb`（与 LTFSCopyGUI 主工程的 `TapeUtils.CMParser` 同源的副本，已去掉读带功能）。

## 限制

- 只读查看，不修改、不保存报告。
- 原始二进制 CM 必须通过 CM 校验（长度 ≥ 4096、校验和正确），否则提示格式错误。
